# miRNA 臂注释歧义标记

[English](README.md) | **简体中文**

本包整理原项目 2026-10-03 的独立标签审计：137 个唯一 miRNA–基因疑似标签，涉及 78 个 miRNA，其中 110 个属于非测试/留出验证集、27 个属于独立测试集。2026-10-28 整理上传，未训练或执行模型推理。

主文件为 `arm_annotation_flags.csv`，字段说明见 `field_dictionary.csv`；主键为 `(arm, gene)`。默认 README 使用英文，原始中文报告保留。

标记规则同时要求：次要臂（原审计中已验证靶点较少的一臂）、与另一臂共享该靶标、自身没有典型位点、另一臂有典型位点。典型位点只指 8mer、7mer-m8、7mer-A1。137 个标签的自身位点为 none 104 个、仅 6mer 33 个，不能将这两类混为一类。

CLASH 不是筛选条件，仅作为额外证据：两臂均曾被 CLASH 检出的标签有 81 个；自身臂/该基因有支持的 1 个，另一臂/该基因有支持的 46 个。因此不能说所有 137 个标签均经 CLASH 验证。CLASH 条件沿用原审计 WT_Detected_8 >= 1，包含所有目标区域；未检出不等于不结合。

这些是待人工核查的疑似歧义，不是已确认错误，也不是 MechKG 识别出的错误标签。后续匹配样本外评分比较未观察到模型给这些标记更低分的证据：B 组总 logit 胜率 0.478（95% 区间 0.418–0.540），图证据和 0.455（0.410–0.507），两者均跨 0.5。完整既有诊断及运行前记录保存在 `diagnostics/`。

`audit/` 保留完整 9,353 行原始角色记录与发夹汇总；这些行不全是疑似标签。`evidence/` 包含相关序列特征、CLASH 检出记录和 miRNA 检出索引；`sources/` 保留原始脚本及 miRBase 映射。原脚本依赖原项目目录，不作为独立复现入口。在本目录运行 `python verify_flags.py` 可核对文件校验值、137 条提取规则及证据一致性。

所有源文件路径、大小和 SHA-256 见 `PROVENANCE.json`。未包含完整原始 CLASH CSV，只发布相关检出记录；未增加模型权重，主模型数据和权重仍使用原 Release。未修改原始输入、审计输出或第三方数据授权。
