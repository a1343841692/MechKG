# 137 个疑似臂歧义标签的样本外评分诊断

日期：2026-10-12（Asia/Tokyo）。模型：当前论文主模型 `mk_ns_nodrop`。仅重用现有预测与解释导出，未训练或执行新推理。

**主结论：未观察到标记标签获得更低的匹配样本外评分的证据。** B 组总 logit 与逐条图证据 Σφ 的胜率区间均包含 0.5；运行前写定的预期未达到。审计可保留为独立的数据质量分析，本结果不能支持“MechKG 能识别这些可疑标签”。也不能据此断言两组完全相同或标签无问题。

## 主比较 B

指标为每个标记标签与其对照集的 P(对照得分 > 标记得分)，平局计 0.5，再对标记标签等权平均。大于 0.5 表示标记标签分数较低。95% 区间按标记 miRNA 聚类重采样 2,000 次，seed=0。

| 分量 | 胜率 | 95% 区间 |
|---|---:|---:|
| 总 logit | 0.478 | 0.418–0.540 |
| 序列贡献 | 0.482 | 0.432–0.528 |
| 图证据 Σφ | 0.455 | 0.410–0.507 |
| 图背景 | 0.483 | 0.421–0.539 |
| 图总分 | 0.472 | 0.417–0.532 |

137 个标签（78 个 miRNA）全部有对照，每个标签的对照数中位数为 95。对照为未标记、无 8mer/7mer 自身位点、同一 val/test 集合且两个端点训练度数落在相同五分位的正例。

序列胜率接近 0.5，未见明显序列项差异，但这不证明所有序列特征已完全平衡。Σφ 的点估计偏向标记标签得分更高，区间仍包含 0.5，不能写成图证据显著更高或更低。

## 口径核对与修正

原模板要求全部标记标签 `site_class == none`，与项目真实审计口径冲突。审计 `arm_annotation.py` 将“典型位点”定义为 8mer、7mer-m8、7mer-A1；137 个标记标签中 104 个为 none，33 个为仅有 6mer，没有 no_utr。全部 9,353 行审计记录的 own_site 与原始特征前三维一致。

本次保留真实 site_class，检查所有标记标签属于 {none, 6mer}；B/C 的无典型位点对照池也取这两类，排除缺失 UTR。增加 B 的精确位点类别匹配敏感性分析：总 logit 0.482（0.425–0.545），Σφ 0.456（0.406–0.507），序列项 0.470（0.424–0.519）。137 个标记全部匹配，对照数中位数 49；结论不变。

C 按用户的文字定义，在 B 条件上再限制次要臂。原模板 C 代码漏掉了 miRNA 度分箱，本次补齐。以上修正在比较得分之前写入 [PROTOCOL.md](PROTOCOL.md)。

## 全部计划比较

| 比较 | 匹配标签 / miRNA | 对照数中位数 | 总 logit 胜率（95% 区间） | Σφ 胜率（95% 区间） |
|---|---:|---:|---:|---:|
| A：全部未标记正例，仅描述 | 137 / 78 | 9,975 | 0.789（0.757–0.824） | 0.524（0.475–0.579） |
| B：无典型位点 + 同集 + 双端点度分箱 | 137 / 78 | 95 | 0.478（0.418–0.540） | 0.455（0.410–0.507） |
| C：B 条件 + 次要臂 | 137 / 78 | 35 | 0.516（0.459–0.574） | 0.491（0.436–0.548） |
| D：同 miRNA 的其他未标记靶标 | 131 / 72 | 6 | 0.523（0.466–0.583） | 0.355（0.300–0.410） |
| B：另精确匹配 none / 6mer | 137 / 78 | 49 | 0.482（0.425–0.545） | 0.456（0.406–0.507） |

A 的总分差异主要伴随明显序列差异：序列胜率 0.868（0.857–0.879），不能用来声称模型独立识别了可疑标签。

D 中标记标签的图证据较高，而序列项较低〔序列胜率 0.718（0.662–0.774）；图总分胜率 0.359（0.298–0.420）〕。但 D 没有匹配位点、基因度或 val/test 集合，也有 6 个标签无对照。其标记端基因训练度均值为 16.22，对照为 7.64；因此不能把这个现象直接归因于标注错误导致的图证据相互强化。B/C 仍是判断这项主张的依据。

## 阈值与匹配残差

| 组 | 标记判正比例 | 按每个标记标签等权的匹配对照判正比例 |
|---|---:|---:|
| B | 46.0%（63/137） | 44.5% |
| C | 46.0% | 50.0% |
| D（仅匹配标签） | 48.1%（63/131） | 47.5% |
| B 精确位点匹配 | 46.0% | 44.1% |

未匹配的总体描述：全部未标记正例判正率为 82.2%，全部未标记无典型位点正例为 54.5%。这两个比例不是 B 的匹配对照比例。CSV 中连续 `prob` 的胜率与 logit 单调等价，不能把它当作阈值判正比例；两者逐分量独立 bootstrap，Monte Carlo 区间端点略有差异。

五分位匹配没有完全消除度数差异：B 中 miRNA 度均值为标记 6.04、匹配对照 6.23；基因度为 16.06、12.40。对应的度数胜率分别为 0.505、0.409，仍有基因度残差。因此应写“按度分箱匹配”，不要写“完全排除了热度”。未因观察结果而更换主分箱或挑选显著分析。

## 数据与验证

- 元数据 10,112 行：验证 8,599、测试 1,513。验证只读取所属留出折；测试每对有 5 个不同模型，共读取 16,164 条评分。
- 标记总数 137，测试 27；审计重复记录先按实体键处理，未扩增正例；次要臂沿用审计定义。
- 各模型训练正例与其本次评分正例无交集；实体键与模型键唯一；数值有限。
- 各通道 Σφ 从 evidence 表求和，背景 = 通道总贡献 − Σφ。pathway 映射至输出 `go`，disease 映射至 `dis`。
- 总 logit = 五个通道贡献 + checkpoint 标量偏置 + residual；确认所有 checkpoint 无 residual 模块、collab 通道为零。旧测试贡献表没有 residual 列，按 checkpoint 已确认的零残差补齐。
- 重建概率与现有概率的最大绝对差为 1.3253e-7，避免从饱和概率反算 logit。
- 验证集逐对逐通道证据计数与 n_sub 完全一致。旧测试贡献导出不含 n_sub，无法用此法独立证明测试证据表逐条完整；测试证据完成了实体键、重复、类型与数值检查，分解依赖已有解释导出。
- 六项回归检查通过：真实元数据与 6mer、验证折选择、测试 logit 平均、测试缺模型、测试重复模型、优化前后聚类 bootstrap 等价。测试文件实际包含六个 test 方法，其中缺模型与重复模型分别检查。

区间条件于固定匹配对照与既有模型，只重采样标记 miRNA；未覆盖对照选择、共享基因或模型训练不确定性。各比较与分量属于诊断性报告，未计算 P 值，也未作多重比较校正。

可用于补充材料的表述：

> Flagged labels did not show lower out-of-fold MechKG scores than unflagged positives without 8mer/7mer sites matched by dataset and endpoint training-degree quintiles: P(control > flagged) was 0.478 (95% miRNA-cluster bootstrap CI, 0.418–0.540) for total logits and 0.455 (0.410–0.507) for summed graph-evidence contributions. The arm-annotation audit therefore remains a model-independent data-quality analysis.
